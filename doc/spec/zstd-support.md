# zstd 対応について

## 概要

メイン辞書ファイル (`migemo-dict`, `migemo-sdict`) を圧縮し
ディスク上のフットプリントを小さくしたい。
そのために C/Migemo に zstd 圧縮されたメイン辞書を読み込む機能を追加した。
読み込む辞書が圧縮されているかどうかは、
読み込みファイル名の拡張子 `.zst` の有無で判断する。

## 詳細

-   `ENABLE_ZSTD` で有効/無効を制御する
    -   デフォルトは有効 (`ON`)
    -   パッケージが見つからない場合は、自動的に無効となる
        -   エラーにしたほうがよさそう
-   `ZSTD_USE_STATIC_LIBS` の時はlibzstdと静的リンクを行う
    -   パッケージにより静的リンクライブラリが提供されない場合はエラーとする
    -   デフォルトは無効 (`OFF`)
-   zstd が有効ならば、インストールする辞書は `*.zst` 版だけにしたい
    -   対象は `migemo-dict` と `migemo-sdict`
